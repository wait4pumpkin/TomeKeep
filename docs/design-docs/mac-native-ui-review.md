# macOS 原生界面体验复审

原生迁移不以“使用 SwiftUI 控件”为完成标准。旧 Electron 客户端经过多轮真实使用优化，凡是旧版在信息获取速度、直接操作、视觉语义或高密度浏览上更好，原生版必须保留其优势，除非有经过验证的更优方案。

本轮使用 `apple-design` 的直接操控、即时反馈和克制原则，以及 `emil-design-eng` 的高频操作不动画、好默认值和细节复利原则进行复审。

| Before | After | Why |
| --- | --- | --- |
| 标签筛选藏在“筛选与排序”子菜单 | 书库和愿望单顶部常驻一键标签条 | 标签是高频缩小范围操作，应直接可见、一次点击完成 |
| 标签筛选无论是否选中都带有类别颜色，且旧哈希会让 BGG 与大宝撞色 | 未选中标签统一为中性描边；选中后只填充类别色并显示白字，不额外添加勾号前缀；采用稳定 FNV-1a 映射八组高区分色 | 颜色本身已经清晰表达“已选中”，无需重复符号扰动标签文字，同时保留类别线索并避免真实数据中的明显撞色 |
| 8–20 列封面模式仍显示作者、ISBN、评分等元数据 | 紧凑模式只显示固定比例封面、状态徽标与两行书名；完整元数据保留在列表和编辑页 | 高密度网格优先识别封面，不在狭窄卡片中堆叠文字 |
| 卡片悬停时缩放、叠加多层阴影和材质 | 仅改变封面描边，不改变布局尺寸；移除高频悬停动画与重材质 | 消除相邻卡片视觉重叠，减少滚动时的合成负担 |
| 封面视图重建时重复读取图片 | macOS 封面使用有上限的内存缓存 | 减少来回滚动时的磁盘读取和图片对象重建 |
| 点击卡片后用独立布尔值打开 Sheet，记录状态可能尚未传入 | Sheet 路由自身携带待编辑记录，并以唯一身份创建 | 从状态模型上区分新增和编辑，保证表单字段完整带入 |
| 列表中标签不可见 | 详细列表恢复最多三个彩色标签及剩余数量 | 在不挤压主要信息的前提下保留分类线索 |
| 将阅读档案、价格记录和数据迁移都提升为一级侧边栏页面 | 侧边栏恢复为书库、愿望单、同步设置三个图标；阅读档案回到书库上下文，价格记录回到愿望单上下文，迁移入口放入设置 | 领域模块不等于用户导航；一级结构应保持老版本的简洁心智模型 |
| 排序、方向和阅读状态集中在弹出菜单 | 恢复老版本的并排图标按钮；再次点击当前排序直接切换升降序 | 高频浏览控制应一次点击完成并持续显示当前状态 |
| 原生 `List` 侧栏让图标随行内容偏移，侧栏过窄且支持意外隐藏 | 改为不可隐藏的 80 pt 固定图标栏、40×40 pt 居中命中区；书库与愿望单置顶，用户、设置等入口置底 | 为窗口交通灯保留合理呼吸空间，同时保持旧版窄侧栏节奏和稳定导航 |
| 标签条嵌在横向滚动容器中，轻微拖动会吞掉点击 | 三个迁移标签直接放入不滚动的前导 `HStack`，保留颜色、选中态和清除按钮 | 当前真实数据只有三个标签；优先保证单击可靠，未来标签数量增长时再采用可换行布局 |
| 排序和阅读状态按钮连续平铺，控制类别难以辨认 | 排序与筛选分别放入独立的圆角按钮组，组内保留选择色和升降序角标 | 恢复旧版“相关操作成组”的视觉层级，同时避免重新引入菜单 |
| 不同宽高比的封面统一裁切填满，窄卡片内容可能越界 | 封面改为在固定 2:3 中性画布内完整缩放，卡片自身裁切到网格列；书名固定占两行 | 不牺牲封面内容来追求满框，并从布局边界上阻止相邻卡片重叠 |
| 侧边栏缺少旧版的语言与外观入口，且愿望单、设置图标改成了另一套语义 | 恢复底部 `EN/中` 语言切换与系统/浅色/深色循环入口；一级入口使用旧版书本、星标、云朵和人物语义 | 迁移不应让全局偏好变难找，也不应无理由改变已经建立的图标记忆 |
| “详细视图”实现为单行 `List`，与旧版信息卡片网格不一致 | 详细视图恢复为自适应多列信息卡片：固定比例封面在左、核心书目信息在右、ISBN 与操作位于底栏；简要视图继续作为高密度封面网格 | 保留旧版“详细/简要”的真实含义，同时用固定边界解决封面尺寸、文字拥挤与卡片重叠 |
| 搜索、筛选、排序和视图切换挤在窗口工具栏及连续按钮带中 | 搜索放在内容控制栏左侧，阅读状态单独成组；排序和视图切换分别成组并靠右，窗口工具栏只保留新增等页面级动作 | 恢复旧版从左到右的任务层级，减少标题栏拥挤，并让各组用途一眼可辨 |
| 应用内切换语言后，搜索占位文本被二次本地化成 `null`，窗口标题仍保留启动语言 | 动态文案先由应用语言解析，再以纯文本交给 SwiftUI；书库与愿望单标题显式使用当前应用语言 | 应用内语言切换必须即时、完整，且不能依赖重新启动或系统语言 |
| 按添加/完成时间排序时所有书籍连续铺排，缺少旧版年月定位 | 详细与简要视图都按年、月分节；同年只显示一次年份，未完成项目独立收尾 | 恢复长书库的时间结构和快速视觉定位，同时不改变标题/作者排序的平铺行为 |
| 简要视图只能点击封面进入编辑，无法像旧版单独查看原图 | 书库和愿望单封面悬停时显示独立放大按钮，以轻量预览窗完整显示本地封面 | 区分“查看封面”和“编辑记录”两种意图，恢复旧版高频能力 |
| 侧边栏人物入口打开完整阅读状态页面 | 人物入口只提供当前用户切换，并在切换后刷新书库状态 | 用户入口只承担旧版已有的用户选择职责，不额外暴露所有阅读状态 |
| 从深色或浅色切回“跟随系统”时仍可能保留先前强制色彩方案 | 仅在明确选择浅色/深色时注入 `preferredColorScheme`；跟随系统时完全移除覆盖 | “跟随系统”必须等同系统当前外观，而不是第三种残留状态 |
| 原生 Target 使用默认生成图标 | 将旧版 1024×1024 TomeKeep 图标制成共享 AppIcon 资产，并同时编入 macOS/iOS Target | 原生迁移期间保留已建立的产品识别，避免用户误认成另一款应用 |
| 固定侧边栏仍由 `NavigationSplitView` 承载，系统可能继续生成隐藏侧边栏入口 | macOS 根布局改为固定 80 pt 侧栏与内容区，不再声明可折叠分栏 | 产品已明确不支持隐藏侧边栏，从结构上移除能力比隐藏单个工具栏项更可靠 |
| 排序与视图按钮使用 plain button 时只有图标形状稳定命中 | 每个图标放入覆盖完整 28×24 pt 按钮面的内容形状，背景与命中区域保持一致 | 分段控件的可点击范围应与视觉按钮边界一致，减少必须点准图案的精细操作 |
| 阅读状态使用高饱和渐变圆、白色图标和投影覆盖在封面上 | 改为更小的浅色状态底、同色细图标与轻描边，并移除投影 | 状态是辅助信息，不应抢过封面与书名；保留扫视识别的同时回到旧版的弱强调层级 |
| 标签筛选无结果时，空状态按理想尺寸收缩，顶部控制栏会随页面高度重新布局 | 书库与愿望单内容画布始终占满可用区域，筛选空状态只替换结果区并明确提示取消筛选 | 筛选改变数据，不应改变页面骨架；高频控制必须稳定停留在顶部原位置 |
| 书库和愿望单有工具栏动作，而设置页没有工具栏，切换时标题栏高度缩短且标题可能沿用系统语言 | 设置页使用当前应用语言显式生成标题，并将真实的“数据迁移”动作放入工具栏 | 相邻一级页面应保持稳定窗口结构；应用内语言不能依赖启动时的系统本地化状态 |
| 顶部图标组只能从选中态猜测含义，系统延迟提示难以快速确认；详细卡片整卡点击打开独立编辑窗，导致复制也误触编辑，且缺少状态、删除与 ISBN 语义 | 顶部筛选、排序和视图按钮悬停即显示短标签；详细卡片恢复右上角阅读状态循环按钮，底栏显示 ISBN 语言/地区并提供独立的复制、关联、编辑、删除操作；编辑直接在卡片内展开 | 图标必须可发现，按钮必须只执行自己的动作；高频小改动应保持上下文，避免窗口跳转打断浏览，也恢复旧版成熟的直接操控模型 |
| 详细卡片标签只能展示，操作按钮缺少悬停反馈，删除图标常态为红色，卡片内边距偏松 | 标签胶囊恢复原位删除与末尾新增；阅读状态及底栏动作使用即时悬停说明，底栏按钮悬停时才显示浅色背景和语义色，删除常态回归中性；封面、文字、标签与底栏间距整体压缩 | 桌面端高密度书库需要低成本直接编辑；危险色只在用户明确指向危险操作时出现，既保留警示又避免每张卡片长期产生红色噪声 |
| 详细卡片关联页面占用底栏按钮，编辑提示暴露实现方式，上半区四周留白导致封面与文字没有形成明确区域，编辑态还重复修改标签 | 移除底栏关联按钮，带来源链接的书名本身成为入口；提示统一为“编辑”；标签只在浏览态原位维护；卡片恢复固定 112 pt 的封面等高上半区，右侧书目信息整体垂直居中，下半区只承载 ISBN、完成日期与卡片操作 | 让内容本身承担最自然的导航意图，避免重复入口；浏览态标签直改和书目编辑各司其职；稳定的上下分区与垂直节奏更接近旧版成熟布局，也能降低逐卡扫视成本 |
| 点击标签新增后，macOS 点击非输入控件不会自动让原生文本框失去第一响应者，空标签输入会一直停留 | 标签输入框只在自身范围内保持焦点；点击同一窗口其他位置时主动释放焦点，并沿用既有规则提交有效标签或关闭空输入 | 桌面端的非文本区域并不天然接管键盘焦点；显式定义“点击外部结束编辑”才能让短暂的原位输入符合用户预期 |
| 详细卡片缺少封面放大入口，封面预览使用独立窗口；简要封面点击直接打开编辑 Sheet，丢失书库浏览位置 | 详细和简要封面悬停均显示放大按钮，预览改为当前页面上的单张大封面遮罩，点击封面外关闭；简要视图点击封面在所在行下展开详细卡片，再由卡片执行标签、状态和内嵌编辑，点击书名仍打开来源 | 查看图片和编辑书目都应从当前对象原位展开并可立即撤销；保持空间上下文比新开窗口或 Sheet 更容易理解，也恢复老版经过验证的交互分工 |
| 简要封面继续叠加阅读状态，展开卡片只能再次点击原封面收起，内容瞬间插入导致下方书目跳动 | 简要封面只承担书籍识别；点击展开卡片外任意位置自动收起；展开、切换与收起使用 200 ms、无回弹的透明度与 0.97 比例过渡，系统减少动态效果时只保留淡入淡出 | 阅读状态在展开卡片中已有明确入口，不必污染高密度封面；外部点击符合临时详情的退出预期，短促且可中断的空间过渡用于解释内容来源而非装饰 |
| 原生心愿单把待购切换、移入书库、比价、标签维护和编辑隐藏到 Sheet 或右键菜单，简要封面点击也直接打开编辑 Sheet | 详细卡片恢复待购切换、最低价链接、移入书库、比价、标签增删、内嵌编辑与删除；简要视图沿用书库的行内展开、外部点击收起和来源标题链接；顶部补回全部/待购买筛选与无标签筛选，软删除提供 5 秒撤销 | 心愿单的核心循环是扫视价格与状态后快速决定购买、整理或移入书库；保持操作就近可见比表面简洁更简单，撤销也比频繁确认或静默删除更符合可恢复操作的安全模型 |

## 后续复审范围

- 逐屏对照旧版书库、愿望单、编辑面板、阅读档案和价格页，不把旧版成熟能力降级为深层菜单。
- 使用真实 366 本书、585 张封面检查不同窗口宽度、8–20 列、深浅色、快速滚动和编辑往返；至少固定回归《白痴》《天朝的崩溃》《寂寞的游戏》三种封面比例。
- 任何新动效都必须说明用途；高频导航、筛选和键盘操作默认不使用位移动画。
- macOS 重新进入用户验收前，至少覆盖标签直接筛选、编辑预填、封面网格无重叠与滚动回归。
