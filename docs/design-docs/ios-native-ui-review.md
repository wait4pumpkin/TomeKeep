# iOS 原生界面对照复审

本复审以已通过使用验收的 PWA 移动界面为交互基线，同时遵循 iOS 的 Tab、NavigationStack、Sheet、滑动操作、Dynamic Type 与 Reduce Motion 约束。目标不是逐像素复制网页，而是保留已经证明有效的信息层级、入口优先级和操作距离。

## 2026-10-29 愿望入口可发现性

按 `ui-ux-pro-max` 的手势替代、语义控件和 44 pt 触控原则，将待购买筛选从排序菜单提升为顶部独立购物车按钮，保留选中背景/实心图标和读屏状态。详细行及封面增加可见更多菜单，明确“已购买，移入书库”；原滑动/长按路径仍保留。书名/元数据与封面编辑使用分离命中区，书名打开有效关联介绍，封面进入编辑，没有关联地址时书名回退编辑。封面上的购物车与更多菜单分别置于右上/右下，不嵌套在编辑按钮的标签内部。沿用共享仓储及同步，不增加“已购买”字段或额外阅读状态；成功给出 3 秒提示，重复 ISBN 按原错误处理。

| Before | After | Why |
|---|---|---|
| 五个同级 Tab，阅读档案和只读价格占用主要导航 | 书库、愿望、设置三个稳定 Tab；档案与价格收纳到设置 | 恢复 PWA 的核心任务优先级，降低选择成本，同时不删除能力 |
| iOS 只有单行列表，未吸收 PWA 的详细/紧凑双视图 | 书库和愿望单均增加自适应封面网格与详细列表一键切换 | 封面浏览是高频视觉识别方式，详细列表保留信息密度 |
| 标签直接放入不可滚动 HStack，窄屏可能截断 | 标签条横向滚动，继续使用稳定哈希生成的高区分色 | 保留 PWA 已验收的一键彩色筛选，并适配 iPhone 宽度 |
| 详细列表没有 PWA/Mac 的年月结构 | 最近添加和完成日期排序按年月分组 | 大型书库更容易建立时间位置感，366 本真实数据下尤为重要 |
| 阅读状态只能进入编辑或依赖隐藏入口 | 详细行左滑直接循环状态，右滑删除；上下文菜单保留完整操作 | 用平台原生、可发现的渐进式操作降低高频任务成本 |
| iOS 无旧数据入口，空库无法验收 | Files 选择或预置迁移包；启动时幂等导入并生成哈希报告 | 让真机使用与 Mac 相同的真实数据，同时保持来源只读和可复核 |
| 真机出现上下黑边、整体控件被兼容缩放 | 为 iOS Target 生成原生 `UILaunchScreen` 并声明 iPhone/iPad 旋转能力；干净重装以清除系统启动画布缓存 | 缺少启动屏会让系统采用旧式兼容画布，破坏原生字号、Safe Area 与可用面积 |
| iOS 图标外侧出现白圈 | 用无透明、无预裁圆角的 1024×1024 全幅图标，由 iOS 统一施加设备蒙版 | App Icon 不应自行裁圆角或保留透明边距，否则会产生双重蒙版与白边 |
| 登录/注册页使用通用书籍符号、解释文案和显眼的高级设置 | 从应用 Bundle 的主图标文件加载正式黑金 Logo；只保留用户名、密码、邀请码和主操作；服务地址移入右上角次级 Sheet；注册页移除显示名称、冗余分组标题及邀请码说明 | 认证页应建立信任并缩短操作路径，低频开发配置不应与登录竞争视觉注意力；显示名称当前没有独立用户价值，注册请求自动使用用户名填充兼容字段 |

登录与注册页的本轮取舍依据 `apple-design` 的层级、克制、触控面积和系统材质原则，以及 `emil-design-eng` 对默认态、次级操作和界面密度的复审方法。表单继续使用系统文本输入、Password AutoFill、Dynamic Type 与 Sheet 语义，不以自绘控件牺牲平台行为。

## 2026-10-04 编辑与列表统一

| Before | After | Why |
|---|---|---|
| 编辑标签依赖逗号文本，新增、移除不易发现 | 书籍和愿望共用彩色可移除标签、输入框和明确添加按钮；保存包含尚未提交的输入 | 保留同样的标签数据，降低输入与漏存成本 |
| 愿望把 ISBN、标签混在基本信息内且没有扫描入口 | 两类表单统一基本信息、ISBN、标签顺序及查询/扫码入口；愿望另有购买计划 | 相同任务采用相同结构，差异限定在购买计划 |
| 元数据关联结果固定显示在 ISBN 分组内 | 两类表单共用顶部材质浮动反馈，3 秒后淡出，减少动态效果时仅淡入淡出 | 关联是整份书目信息的操作反馈，不是 ISBN 的持久状态 |
| iOS 标题和多枚操作按钮挤在同一行 | 底部 Tab 标识当前页面，顶部去掉重复标题，为操作留出空间 | 不新增标题行或占用列表面积 |
| 愿望有单独无标签按钮 | 使用与书库一致的 TagFilterBar，移除无标签入口及旧筛选值 | 一致的筛选状态与视觉语义 |

旧 Electron 无优先级编辑控件；原生端保留新增的优先级能力与已有数据。按书名关联豆瓣为原生新增的标题/作者候选搜索，旧桌面对应的资料补全路径是 ISBN 查询及豆瓣 URL 导入。账户显示名仍被 PWA 设置及旧认证契约消费，因此数据库字段与 API 在双轨期保留；原生当前账户统一展示用户名，最终旧端退役时再清理账户 `name`，不要误删阅读档案的姓名。

## 2026-10-04 列表密度与滚动层级

- 书库年月以普通列表行呈现，不使用悬浮 Section header；滚动时随内容离开屏幕，不覆盖书目。
- 两类列表统一紧凑工具条（17 pt 图标、44×44 pt 点击区域），不用额外导航栏占位。iOS 18 及以上向下滚动超过 80 pt 后将上下留白各 8 pt 收为 0；回到 16 pt 内恢复，分离阈值避免布局反馈抖动。iOS 17 保留固定工具条。
- 标签默认收起，点击标签按钮展开；工具条徽标始终提示已选数量。收起不清除筛选，展开后可取消或清空。展开的标签使用 subheadline 字号及至少 44 pt 的点击高度，移除不参与 iOS 自适应网格计算的列数滑块；Mac 原有列数控制不变。
- 详细列表减少内边距、封面间隔；书名、作者、ISBN/出版社、标签均保持单行，长文本省略，编辑页保留完整原始值。封面网格缩小行距，标题保持单行；不修改数据。
- 阅读进度条保持稳定，底部新增同步指示灯：只在实际同步且应用前台时以 1.6 秒透明度往返呼吸，空闲静止、失败橙色；Reduce Motion 下静止。依据 `animate`，动效用于同步状态反馈，而不是暗示阅读数正在变化。
- 删除“本机书库”重复数量。原数字是本地工作集总数，不是未上传数量；阅读分母继续代表当前筛选结果，数据仍自动双向同步并支持离线。
- 书库底部姓名为当前阅读档案，而非认证账户；iOS 可点击直接选择已有档案，档案管理仍在设置。切换认证账户需设置 → 账户 → 退出登录，再登录另一账号，不混用两种身份。

本轮仅修改原生呈现层及测试，不改同步/API/数据结构；旧 Electron 与 PWA 保持原样。编译与单元测试不替代真实数据下的视觉、滚动和大字号验收。

## 2026-10-05 优先级与设置收敛

本节取代上轮“仅同步灯呼吸、进度长条静止”及“保留原生优先级功能”的取舍。

- 旧 Mac 无优先级编辑，旧 PWA 仍消费 priority 字段。删除原生双端优先级编辑、排序、列表/卡片/辅助功能展示及专属颜色图标；已保存的 priority 排序回退到最近添加降序。数据字段、既有值、导入和同步协议保持不变，编辑其他字段不重置历史优先级；愿望仍保留待购买标记。
- 呼吸改为阅读进度长条本身透明度 1 ↔ 0.78，延续 1.6 秒往返曲线；不改变进度比例或位置，不依赖同步是否进行。只在前台呈现，Reduce Motion 下静止。依据 `animate`，以克制明暗而非位移实现用户明确要求的长条效果；真实效果需要真机复验。同步灯保留静态状态颜色。
- 设置保留账户身份、退出、管理员邀请码、实际同步状态和手动重试；iOS 档案/价格管理入口保留；服务设置复用认证页配置 Sheet，与迁移一同收纳到默认折叠的高级设置。
- 删除重复用户名、“SwiftData/系统钥匙串”等实现细节、Cloud/局域网开发提示、旧目录/离线解释、“不占用标签栏”说明；删除设置内已被正式认证门禁替代的登录/注册分支。同步结果只在同步分组出现，避免重复反馈；Mac 顶部重复迁移按钮也移除。
- 不删除迁移器和历史价格，二者仍承担数据恢复与桌面比价结果查看；不变更服务端或旧客户端。

## 仍需完成的体验门禁

2026-10-29 输入框长度回调：书库/愿望表单原位标签输入的最大宽度从 220 pt 收紧为 140 pt，保留胶囊背景和 44 pt 确认触控区；长标签仍可在输入框内编辑，不限制标签字符数，焦点与候选交互不变。

2026-10-29 配色补充：按用户要求，常用候选恢复 TagPalette 原有类别色文字/浅色背景，与同名已选标签保持一致；适用于表单和 Mac 卡片的共用候选组件，替代此前中性候选样式。

2026-10-29 胶囊及键盘修正：标签加号与手输态使用同一 accent 低饱和胶囊背景，与已选标签保持相同内边距和视觉高度；44 pt 触控区域独立于背景。移除标签展开后的主动聚焦，用表单共享 FocusState 解除书名/作者/出版社/ISBN 的既有焦点，点击加号先看候选，点击输入框才弹键盘。沿用 `ui-ux-pro-max` 的原生焦点与触控规则，不改保存/同步边界。

2026-10-29 原位标签输入：按用户指定布局替代表单 Popover，已选标签后只保留加号；点击后原位显示输入框与确认图标，下方才显示“常用标签”和候选，保持无搜索。ISBN 与收起态标签使用同一 44 pt 行高/零上下内边距，保留触控区，移除多余背景/文字入口；多标签与大字体仍可自然换行。候选选择保留输入内容，输入框提交或失焦后收起；Mac 详细卡片现有 Popover 不变。依据 `ui-ux-pro-max` 的完整标签重排与原生 FocusState 指引实现，不添加自定义动画。

2026-10-28 密度回调：移除愿望详细列表元信息中的重复“待购买”文字行，只保留独立购物车按钮和读屏状态；切换购买标记不再增加一行内容。用户确认标签精简方案且不需要搜索：表单只保留已选标签与添加入口，轻量 Popover 展示全部可用标签，可连续选择；手输新建按需展开，不自动弹键盘。Mac 卡片复用面板；候选去除重复加号，使用中性背景，已选使用原标签色；视觉内边距收紧但保留 44 pt 触控区。面板内容高度随标签变化，超出 220 pt 滚动，适配字体放大；按 `ui-ux-pro-max` 的信息分层、触控及原生焦点原则实现。

2026-10-28 快捷操作初版（标签呈现已由上述密度回调替代）：两类标签表单增加已用标签建议（两类记录合并计频、每记录去重、排除已选），44 pt 最小触控区，8 pt 间距，提供明确添加读屏标签；Mac 卡片加号使用轻量 Popover 展示同一建议，按需加载而非逐卡查询。iOS 愿望列表文字区域使用编辑 Button，旁侧购物车为独立 Button；封面编辑 Button 外覆盖独立购物车，避免嵌套 Button 或父级点击手势导致同时进入表单。保留 swipe actions、上下文菜单、表单以及原有 pending/自动同步。依据 `ui-ux-pro-max` 的触控与手势区域分离原则，不重做已验收的布局和视觉体系；大字号、横屏及深浅色的最终视觉仍需真机复验。

- 用 iPhone 13 Pro 的 366 本真实书库复查首屏信息密度、滚动帧率和封面裁切。
- 连续 ISBN 扫描、重复抑制、实时框选、批量状态反馈和安全收尾已实现并安装真机；仍需用至少两本实体书完成连续识别和回库结果验收。
- 愿望单已补充封面/详细视图、快捷筛选、滑动切换待购买/移入书库/删除和撤销；仍需用 219 项真实数据复审信息密度与手势冲突。
- 完成 VoiceOver、超大 Dynamic Type、深浅色、Reduce Motion 和离线重启验收。
- 验证豆瓣候选关联、验证码恢复、本地封面缓存和跨端同步的真实链路。
